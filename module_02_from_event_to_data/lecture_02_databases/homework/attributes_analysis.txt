# Анализ атрибутов сущностей products и employees

## Сущность: products

### Атрибуты:
- product_id  
- product_name  
- category_id  
- price  

### Обоснование атомарности:

- product_id — содержит одно уникальное значение и не делится на части  
- product_name — содержит одно название товара без списков или повторяющихся значений  
- category_id — содержит одно значение, указывающее на категорию  
- price — содержит одно числовое значение  

Все атрибуты являются атомарными, так как не содержат множественных значений и повторяющихся групп.

---

## Сущность: employees

### Атрибуты:
- employee_id  
- first_name  
- last_name  
- shop_id  
- city_id  
- position  
- hire_date  

### Обоснование атомарности:

- employee_id — уникальное значение для каждого сотрудника  
- first_name — содержит только одно имя  
- last_name — содержит только одну фамилию  
- shop_id — содержит одно значение, указывающее на магазин  
- city_id — содержит одно значение, указывающее на город  
- position — содержит одну должность  
- hire_date — содержит одну дату  

Все атрибуты являются атомарными, так как каждое поле содержит одно неделимое значение и не включает списки или повторяющиеся группы.
